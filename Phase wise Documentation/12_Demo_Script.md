# Phase 8 -- Project Demonstration Script

## Introduction

Hello everyone. Today I am presenting **BlogNest, an AI-Powered Blog
Management API**.

BlogNest is a backend REST API designed to make blog management simpler
and more organized. It provides blog management, user access control,
comments, content organization and AI-assisted writing.

## Technology Stack

The project uses Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt.js
and Google Gemini AI.

## Demonstration

First, I will show the project structure and start the backend server.

Next, I will demonstrate user registration and login.

After authentication, I will demonstrate blog creation and retrieval.

Then I will demonstrate the AI features: - AI blog generation using
`/api/ai/generate-blog` - AI summarization using `/api/ai/summarize`

Finally, I will explain the security features, including JWT
authentication, password hashing, role-based access, validation,
sanitization, rate limiting and structured logging.

Thank you for watching the BlogNest project demonstration.
