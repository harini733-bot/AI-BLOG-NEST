# Phase 4 -- Project Planning

## 1. Project Planning Objective

The project is organized into eight phases so that ideation,
requirements, design, development, testing, documentation and
demonstration can be submitted separately.

## 2. Work Breakdown

### Phase 1

Identify the blog-management problem and define the BlogNest solution.

### Phase 2

Define users, features, functional requirements, security requirements
and environment requirements.

### Phase 3

Design the layered architecture, MVC structure, database entities,
relationships and blog lifecycle.

### Phase 4

Plan development activities, team coordination and submission
activities.

### Phase 5

Develop the Node.js/Express backend, MongoDB/Mongoose layer,
authentication, authorization, blog features, comments and AI services.

### Phase 6

Test registration, login, blog creation/retrieval, AI generation and
summarization.

### Phase 7

Prepare the project report and API/technical documentation.

### Phase 8

Prepare the demonstration video, API testing video and screenshots.

## 3. Development Sequence

1.  Create project folder.
2.  Create and open the Server folder in VS Code.
3.  Run `npm init -y`.
4.  Create `server.js`.
5.  Create models, controllers and routes folders.
6.  Install Mongoose.
7.  Configure MongoDB connection and schemas/models.
8.  Implement remaining backend features.
9.  Run API testing.
10. Prepare final submission.

## 4. Submission Checklist

-   All eight folders created.
-   Documentation uploaded.
-   Actual source code uploaded.
-   Testing screenshots uploaded.
-   Final project report uploaded.
-   Demo links added.
