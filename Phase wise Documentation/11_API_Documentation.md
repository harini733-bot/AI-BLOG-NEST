# BlogNest API Documentation

## 1. API Testing Interface

The project report identifies Postman or Thunder Client as the API
testing interface.

## 2. AI Endpoints

### Generate Blog

**Endpoint:** `/api/ai/generate-blog`

**Purpose:** Generate structured blog content from a high-level topic or
theme.

### Summarize

**Endpoint:** `/api/ai/summarize`

**Purpose:** Produce a concise summary from longer article content.

## 3. Other API Areas

The project report documents these testing areas: - User Registration -
User Login - Create Blogs - Fetch Blogs - Generate AI Blogs - Summarize
Blogs
