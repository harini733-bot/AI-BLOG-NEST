# Testing Evidence Checklist

Place actual screenshots in this folder or in a `screenshots` subfolder.

## Required Evidence

1.  User registration request and response.
2.  User login request and response.
3.  Authorized blog creation.
4.  Blog retrieval.
5.  AI blog generation.
6.  AI summarization.

## Recommended Additional Evidence

7.  Unauthorized request.
8.  Invalid token request.
9.  Validation/error response.
10. MongoDB record after successful operation.

## Screenshot Naming

-   `01_User_Registration.png`
-   `02_User_Login.png`

-   `04_Fetch_Blogs.png`
-   `05_AI_Blog_Generation.png`
